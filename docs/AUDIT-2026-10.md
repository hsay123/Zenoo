## What is already correct (do not regress)

- API authorization is server-side (`requireRole`); `DEV_AUTH_BYPASS` refused in
  production (`env.ts:91-98`).
- Contract money rules: task settled at most once, cumulative payout ≤ budget,
  effects-before-interaction (`JobEscrow.t.sol`).
- Backend verifies chain id, contract address, receipt status and the exact
  `TaskSettled` event before `is_mock=false` (`chain.ts:155-179`).
- Marketing makes **no** fake logo/testimonial/metric claims and hedges on-chain
  language (`CredibilityStrip`, `landing.ts:258`).
- Exports/receipts omit contributor identity.
